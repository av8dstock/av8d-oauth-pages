鄉民晨報 隱私權政策

最後更新：2026-09-29

這是什麼程式

「鄉民晨報」是 YouTube 頻道「鄉民投資」經營者自用的內部報表程式，只有頻道經營者本人會授權與使用，不對外提供服務。

讀取哪些資料

經頻道經營者本人授權後，程式以唯讀權限讀取該頻道自己的：

  • 目前訂閱人數（YouTube Data API）
  • 指定期間的新增與流失訂閱數（YouTube Analytics API）

程式不讀取任何其他使用者的資料，也沒有上傳、修改或刪除任何內容的權限。

資料怎麼使用與保存

  • 讀到的數字只用來產生給頻道經營者本人看的報表訊息。
  • 授權憑證只保存在頻道經營者自己的電腦上。
  • 資料不出售、不分享給任何第三方，也不用於廣告。

本程式使用 Google API 取得的資料，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規範。

如何撤銷授權

可隨時到 Google 帳戶的第三方存取權限頁面 移除「鄉民晨報」的存取權。

Privacy Policy (English summary)

Xiangmin Morning Report is a private tool used only by the owner of the YouTube channel "鄉民投資". With the owner's authorization and read-only scopes, it reads that channel's own current subscriber count (YouTube Data API) and subscribers gained/lost for a date range (YouTube Analytics API), solely to produce a report for the owner. Credentials are stored only on the owner's computer. No data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: av8dstock@gmail.com
